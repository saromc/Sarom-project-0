## Fitness Planner

A private, single-user fitness planner website (`index.html`, `styles.css`, `app.js`).
No server, no account, no tracking — data is saved in your browser's local storage.

**Open it:** double-click `index.html`, or enable GitHub Pages (Settings → Pages → deploy from branch, root folder).

**Tabs**
- **Today** – calories/macros vs. your targets, today's planned workout (tick items off), what you logged, 14-day calorie chart, daily notes.
- **Food** – log meals (calories, protein, carbs, fat); one-tap re-add of recent foods.
- **Gym** – log exercises (sets, reps, weight, or minutes for cardio); per-exercise history chart.
- **Weekly Plan** – a Monday–Sunday template of what you plan to train.
- **Body** – body weight / waist log with trend chart.
- **Settings** – your own daily targets, kg/lb, JSON backup export/import, CSV export.

Data lives only in the browser you use. Export a JSON backup regularly; use Import to move it to another device.
